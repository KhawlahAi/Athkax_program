# التجارب واختبارات A/B والاستدلال السببي

## المشروع الختامي

**السؤال:** هل إضافة خيار «تجربة مجانية لمدة 7 أيام» في صفحة الأسعار يرفع نسبة التحول إلى اشتراكات مدفوعة؟

**المقاييس:**
*   **المقياس الرئيسي:** نسبة المستخدمين الذين أتموا الاشتراك المدفوع ÷ عدد الزوار الذين وصلوا إلى صفحة الأسعار.
*   **مقاييس الحماية:** متوسط الإيراد لكل مستخدم (للتأكد من عدم انخفاض الأرباح الإجمالية)، ونسبة الإلغاء الفوري بعد انتهاء التجربة المجانية.

**التصميم والتوزيع:**
*   **الفرضية:** تقديم تجربة مجانية يشجع الزوار على تجربة الخدمة ويقلل حاجز التردد، مما يزيد احتمال الاشتراك الفعلي.
*   **وحدة العشوأة:** المستخدم (User ID أو الكوكيز) لضمان استقرار الواجهة.
